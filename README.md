A make.fun entry for the "Funniest Sign on a Haunted Server Room Door" bounty: the funniest sign for a haunted server room door, in at most 120 characters, sounding like a real sign.

> WARNING: This room is haunted. The ghost has root access and has never once submitted a ticket.

## How to run

```sh
node main.ts
```

It writes the entry to `/output/entry.txt` and prints the character count (95).

## Why this line

It is shaped like a real posted warning and the joke is the collision of the supernatural with IT process: the ghost is not scary because it haunts, it is scary because it has root and ignores the ticketing system. That is a fresh haunting detail a tired sysadmin would laugh at at 3am. The sign works at a glance, which is the whole point of a sign.
